## ADDED Requirements

### Requirement: 高像素點陣圖尺寸與清晰度檢測

系統 SHALL 支援限額內的高像素點陣圖，並以原圖像素及既有檢測尺度判定尺寸與清晰度。

#### Scenario: 高像素 RGB PNG

- **WHEN** 使用者在獨立印前檢測、網頁下單或訂單普通檢測提交支援的高像素 RGB PNG
- **THEN** 以原檔寬高及該入口現行尺寸規則執行檢查，並在訂單單筆與普通批量中照常執行清晰度檢測
- **AND** 上傳時保存原檔位元組

#### Scenario: 分塊與預覽

- **WHEN** 支援的高像素點陣圖進入訂單清晰度檢測
- **THEN** 原像素尺度的分數、模糊面積與通過或警告判定須對應既有演算法，並在縮小的預覽上顯示標記

#### Scenario: 超出檢測資源限額

- **WHEN** 檔案超過資源限額、檢測等候逾時或所需解碼失敗
- **THEN** 回傳具體且可理解的未完成原因，不將未完成的必要檢查標記為通過

#### Scenario: 既有格式與模式

- **WHEN** 使用者提交一般大小的檔案，或使用 AI／PDF 或多畫板簡易模式
- **THEN** 按原流程執行適用的尺寸、轉外框、嵌入圖解析度或畫板數檢查，RGB 不構成拒絕條件
