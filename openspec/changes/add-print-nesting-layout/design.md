## Context

印刷排版主流程改為「印刷池」可視化作業（存量舊單據可不強制回填）。

## Target Flow

```
大圖訂單確認 → 內部工單(B)
  → 捲材項次（寬×高×數量 = 矩形圖塊 + 材料）
  → 進入印刷池（按材料聚合）

印刷池 UI：
  左：各材料 / 各門幅捲料
  右：長條可視化
      1) 優先排「已用一半」的舊料（剩餘長度）
      2) 預留一條「新料」給排不下舊料的大圖
  工人覺得可以印了 → 截斷鎖定 → 生成印刷單
```

## Goals
- 工單產生後項次自動進池（need_print + 未印完）
- 左選材料，右看最佳排版長條
- 舊料優先、新料預留
- 截斷鎖定 → 印刷單（piece=reserved）

## Non-Goals (本輪)
- 異形 nesting
- 強制改 lotmpr 扣料
- 存量歷史單據回填

## Decisions
- 產品規格：寬 cm、長 m（與庫存無關）
- 排版計算內部 mm
- 主入口：Client Action「印刷池」
- 截斷：選定長條上的截止長度，該長度內圖塊鎖定進印刷單
