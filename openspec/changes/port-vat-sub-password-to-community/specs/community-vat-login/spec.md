## ADDED Requirements

### Requirement: 社区版统编主子密码
SaaS 社区版 SHALL 支持已在企业版实现的同统编主子密码登录，使用相同客户归属和原有业务权限，并保留社区版现有兼容逻辑。

#### Scenario: 主子分别登录及改密
- **WHEN** 客户使用同一统编及有效主密码或子密码登录
- **THEN** 系统保持同一客户及 Odoo 用户并记录 main 或 sub 身份
- **AND** 分别改密、密码冲突、首次改密和登出行为与企业版一致
- **AND** 子密码以哈希保存，旧主密码保持兼容

#### Scenario: 社区版兼容性
- **WHEN** 客户资料没有企业版 contact_address_complete 字段
- **THEN** 继续使用社区版既有地址拼接逻辑
- **AND** 保留客户与供应商模板下载、员工表单和既有模型导入

### Requirement: 社区版子账号预览隐藏价格
SaaS 社区版 SHALL 在网页下单预览原 nop 判断之前检查子账号身份，隐藏子账号的预估价钱表头、行金额和预计总价。

#### Scenario: 子账号预览
- **WHEN** 子账号打开订单预览
- **THEN** 无论 nop 值为何均不显示价格
- **AND** 保留产品、尺寸、数量、价格计算与下单流程

#### Scenario: 主账号预览
- **WHEN** 主账号或其他原有身份打开订单预览
- **THEN** 继续按原 nop 条件决定是否显示价格
- **AND** 不改变客户 nop 字段值
