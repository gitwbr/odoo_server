# Change: 印刷池全量捲料展示、耗盡歸檔、印刷單扣料

## Why

印刷池目前只顯示「有剩餘的舊料」+「一卷新料」，其餘同尺寸捲料被過濾掉，導致查不到之前舊單占用的捲。  
另外，庫存扣減仍依賴「捲料扣料表」掃碼（`dtsc.lotmpr`）；印刷單生成後並未扣料，與「生成印刷單就應扣料」的新流程衝突，掃碼扣料應退役。

## What Changes

1. **印刷池展示當前材料的全部在用捲料**
   - 同 `product.template` 下所有未歸檔、有庫存（或仍有印刷歷史）的 `stock.lot`
   - 排序：有排版內容（歷史/待排）在上，空捲在下
   - 空捲仍顯示以便查看／選用／歸檔

2. **「材料耗盡」歸檔**
   - 捲料條帶上新增按鈕：材料耗盡 → 標記該 `stock.lot` 為印刷歸檔
   - 歸檔後不再出現在印刷池「在用」列表
   - 新增選單／頁面：查詢所有已歸檔捲料（可篩選材料、日期、單號）

3. **印刷單扣料取代掃碼扣料**
   - 生成／確認印刷單時，依該捲截斷長度（或已用長度）對綁定的 `stock.lot` 做庫存扣減（對齊現有 lotmpr 的庫存→生產調撥思路）
   - 同步讓對應 `dtsc.makeinline` 視為已扣料（`is_stock_off`），內部工單入庫檢查不再擋住
   - 開啟本流程後：**隱藏**「捲料扣料表」掃碼入口（或對印刷排版材料停用），避免雙重扣料

## Impact

- Affected specs: `print-nesting`（修改）
- Affected code:
  - `dtsc_print_nesting`：`print_pool` 條帶、`stock.lot` 歸檔欄位、歸檔列表、印刷單扣料
  - `dtsc`：捲料扣料表選單可見性／或 `is_stock_off` 計算擴充（盡量少改）
- **BREAKING**：啟用印刷單扣料後，原掃碼扣料路徑對捲料印刷項次不再使用
- 不直接改資料庫業務資料；新欄位透過模組升級加欄

## 已確認（2026-10-22）

1. **扣料時機**：生成印刷單時扣；刪除印刷單時返還。
2. **扣料數量**：沿用舊捲料扣料表邏輯，扣**才數**（`makeinline.total_size`／`lotmprline.yujixiaohao`），因庫存捲料以才計。
3. **掃碼入口**：**保留**「捲料扣料表」與庫存中的捲料扣料總表；自動扣料行為與掃碼相同，只是免掃、自動寫入同一套 `dtsc.lotmpr`／`lotmprline` 並執行扣料。
4. **排版展示**：在捲料扣料總表（`dtsc.lotmpr`）表單中可查看該捲相關印刷排版預覽。
5. **材料耗盡**：印刷池按鈕觸發（對齊舊 lotmpr「材料耗盡」`confirm_btn`），並可查詢已歸檔捲料。
