## ADDED Requirements

### Requirement: 用户可重新开始助手对话
系统 SHALL 提供「清空对话」操作，结束当前身份的旧会话，使后续查询不再传入旧问题、旧回答及旧查询资料，同时保留后台排错记录。

#### Scenario: 清空后重新查询
- **WHEN** 有助手使用权限的用户在标题栏「⋯」菜单选择清空对话并确认
- **THEN** 系统归档该身份全部 active 会话并建立空白会话
- **AND** 后续模型消息只包含新会话的内容，刷新页面也不恢复旧消息
- **AND** 不删除业务资料、旧消息或后台问答及 Gateway 日志

#### Scenario: 不得重置其他用户
- **WHEN** 客户端传入其他用户、客户或会话标识
- **THEN** 重置范围仍由当前登录身份决定
- **AND** 无助手权限、未登录或缺少有效 CSRF token 的 HTTP 重置请求被拒绝

#### Scenario: 迟到的响应与旧页面
- **WHEN** 清空前的历史加载或查询响应迟到
- **THEN** 界面忽略该响应，不覆盖新会话或恢复旧结果操作
- **AND** 携带旧会话标识的查询、客户选择及分页请求在执行前被拒绝，并提示用户在更新后的会话重新输入问题

#### Scenario: 清空失败或取消
- **WHEN** 用户取消确认
- **THEN** 不发送重置请求或改变当前会话
- **WHEN** 无法确认重置成功
- **THEN** 界面明确提示失败，先重新读取后台当前会话才能继续查询，不显示清空成功
