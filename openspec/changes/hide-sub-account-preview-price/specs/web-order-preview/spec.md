## ADDED Requirements

### Requirement: 子账号预览价格显示
系统 SHALL 在网页下单预览中先判断当前会话是否为统编子账号，子账号隐藏预估价格，其他身份继续按原客户 `nop` 字段判断。

#### Scenario: 子账号不显示价格
- **WHEN** 统编子账号预览网页订单
- **THEN** 不显示预估价钱表头、行金额或预计总价
- **AND** 无论原客户 nop 字段为何值均适用
- **AND** 产品、尺寸、数量及下单功能保留

#### Scenario: 主账号仍按原字段判断
- **WHEN** 主账号或其他原有身份预览网页订单
- **THEN** 仅在原 `nop === false` 条件成立时显示价格
- **AND** 不改变 nop 字段值或原有计算逻辑

#### Scenario: 身份来自登录会话
- **WHEN** 客户资料接口返回子账号标记
- **THEN** 标记由后端已验证的客户会话与主子角色决定
- **AND** 客户查询参数或选择其他客户不能改变登录账号身份
