# 企业版 AI 助手改动总览

## 交付状态

本次及前序会话的代码改动已落在企业版目录。未部署正式环境，未重启 Odoo/Gateway，未运行模块升级，未直接修改数据库结构或资料。真实测试库只读验证此前被自动审批额度限制拒绝；50题真实问答及各岗位对数仍待执行，不能把隔离测试称为线上验收。

## 一、安全与权限修复

- 配置密钥读取、网关执行、身份解析、聊天记录内部操作改为私有方法，禁止通过通用 RPC 直接调用。
- AI 设置读取和保存检查 DTS-C 管理员权限；保存还检查记录写权限。
- 问答与历史公开入口采用实际登录身份，不接受客户参数冒充。
- 通用查询检查真实内部用户权限；关联展开及集合计数分别检查来源与目标范围。
- 签名分页绑定用户、公司和时区，有效期15分钟，拒绝伪造和跨用户引用。

## 二、原有功能修复

- 通用查询使用动态字段表格，按实际模型跳转，修复工单链接错误。
- 数字0不再变成false或空白。
- 分组、多模型结果和刷新后的历史结果可展示。
- 历史读取在数据库查询时限量，并稳定按日期/ID排序。
- 最近两条助手消息可带入有界查询资料，供多轮追问辨识对象。
- 区分单次请求与整轮超时：默认单次30秒、整轮180秒、Odoo外层再等待15秒；整轮上限300秒。
- Gateway 使用可取消异步 agent/tool 调用，保留超时前完成的工具结果，并标准化文本块回答。

## 三、第一/二批：扩大基础查询与关联分析

- capabilities 动态目录与“我能查什么”按钮、示例问法。
- 受限 all/any/not 条件树，最多3层、20个条件。
- 明细稳定分页，默认20/最大100笔，继续最多offset5000；大结果裁剪后按实际返回数量继续。
- 采购/销售/库存/财务标准明细沿批准业务关系纳入，仍受菜单目录和ACL限制。
- relations 发现可用正反向关系；related 展开Many2one、One2many和Many2many。
- exists/not_exists 关联筛选，例如没有有效S的母单。
- 跨模型union/intersection/difference去重计数，B/G不再直接相加。
- 集合来源及目标各最多5000笔，超限明确拒绝部分总数。有效生产/施工/S来源默认排除cancel。
- 查询集合主要变化、来源单据变动/不可读或分页过期时要求重新查询。

## 四、第三批：指标与期间计算

新增 metric_catalog、metric、period_analysis 三种通用操作。

15项代码定义（实际目录按当前账号可读模型过滤），版本 `2026-09-09.1`：

| 指标 | 口径 |
|---|---|
| 有效大图订单进单数 | create_date期间；非cancel；计A/F/E/M/D记录，含M |
| 大图订单逾期未出货 | is_delivery=false、非cancel/closed、estimated_date早于查询时刻；期间按创建日期 |
| B/C/G/T未完成数（4项） | 工单创建日期；排除cancel及各自完成状态 |
| B/C/G/T单据完成比例（4项） | 目前完成工单数÷期间创建的有效工单数，非母单/产品行比例 |
| E重制单占有效进单比例 | E数÷有效A/F/E/M/D数，非原单重制概率 |
| 未结清客户发票数 | out_invoice、posted、amount_residual>0，期间按invoice_date |
| 未结清供应商账单数 | in_invoice、posted、amount_residual>0，期间按invoice_date |
| S草稿数 | draft；期间按S创建日期 |
| S草稿且交货时间已过 | draft且delivery_date早于查询时刻；非物流签收逾期 |

B完成状态stock_in；C为succ；G为succ/stock_in；T为succ。大图订单逾期和工单完成状态依据现有overview_dashboard相应读取逻辑整理，本次没有执行其Server Action，也没有把整个概览财务/采购算法照搬为AI指标。生产需求/转单率等原报表仍待逐项复用及对数。

期间计算：

- 明确日期字段与本期/基期起讫，输出原值、差额、变化率、两期天数。
- 同比/环比由模型先换算明确日期，服务端执行确定性计算；不自动保证任意自然语言已正确选期间，真实问答须验收。
- 零基期返回不适用；无记录的平均/最大/最小值保留空值，不错误补0。
- 日/月趋势最多60个时段，数量/可加总空时段补0，支持部分月日期范围。
- Monetary字段期间比较需过滤到单一币种。普通Integer/Float金额字段不会自动识别币种或税别，须明确业务字段；不把总和自动称为营业额。
- 指标可查看同口径原单据；完成比例明细显示分母集合。

## 五、第四批：使用与交付

- 主管、业务、生产、采购、财务五类常用问题模板。
- 统计表格与可展开条形图；图表按首个数值列绘制、最多60行，负数标真实数值，条长用绝对值。
- 展示查询时间、时区、范围、条件、指标版本与说明。
- “重新查询”使用原结构化条件重新校验执行；期间比较可分别查看本期/基期原单据。
- CSV导出只导出当前显示结果，明确部分/当前结果，不自动读取全库；支持中文、引号、换行、零值及公式文本保护。未提供XLSX。
- 收藏问题、移除收藏、命名当前对话采用浏览器localStorage，按账号/数据库/线程隔离；最多20条收藏。不跨设备同步，不新建数据库会话或资料。
- 前端阻止同一面板重复并发提交；历史已截断结果不继续使用可能造成漏行的旧分页按钮。
