# Change: 企业版统编客户增加一组子密码

## Why
每个统编客户目前只需要一个子身份。用户已确认沿用相同统编，以不同密码识别主子，业务动作和权限保持一致，并于 2026-11-11 明确授权实施；数据库变更通过模型代码和正常模块升级完成，不直接修改数据库。

## What Changes
- 保留现有统编及主密码，增加一组可设置、重设、停用的子密码，默认不启用。
- 同一登录入口按密码确定 main/sub 身份，继续绑定原客户及同一 Odoo 用户权限。
- 会话记录统编账号 ID 和主子身份，客户页面显示身份，业务逻辑不按身份分权。
- 改密按旧密码确定更新目标，防止主子密码相同，并修复空主密码时旧密码未校验的问题。
- 新增子密码以哈希存储；不批量修改原有账号或主密码。

## Impact
- Affected specs: `vat-customer-login`
- Affected code: 企业版 dtsc 的模型、登录/改密控制器、客户页面、后台账号视图及回归测试。
- 不改 SaaS 社区版、不新增客户资料或 Odoo 用户、不改订单归属和业务权限。
- 新字段和视图需要正常升级企业版 `dtsc` 模块后生效。

## Authorization
本提案记录对话中已经确认并获准实施的范围，无新增业务权限决策。
